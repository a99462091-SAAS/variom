# VARIOM — Owner Decisions: Creative Taxonomy and MAX Migration

**Date:** 2026-11-19  
**Status:** Owner-approved migration policy; individual source records remain unapproved.  
**Authority:** Subordinate to `00-product-vision-simplified-ux-v2.md`. This record captures the owner's approval of the recommendations in this document; it does not approve production imports or override the VARIOM product taxonomy.

## 1. Owner-approved decisions

The owner approved the following recommendations:

1. **No bulk adoption of the 144 MAX styles.** The library is a source of candidate concepts, not a ready-made VARIOM production library.
2. **Adopt selectively and progressively.** Choose a small, useful candidate set for each relevant VARIOM studio, then validate actual outputs, feasibility, cost and quality before approval.
3. **P1, P2 and P4:** retain suitable concepts as candidates and adapt them to VARIOM. Do not import records unchanged.
4. **P3:** keep Carousel within Image Studio only; it is not part of Monthly Content. Hold P3-013 through P3-018 until the canonical ID/name conflict is reconciled against the prior approved mapping. Do not rename or remap these IDs by guesswork.
5. **V1:** preserve the distinction between genuine customer/user testimony, paid creator content, acted/scripted scenarios and synthetic presenters. Never fabricate real customer experiences, reactions or endorsements.
6. **V2:** retain suitable product-demonstration concepts as candidates. V2-016 (voice-over) and V2-017 (on-screen annotation) should be standalone styles only if each creates a meaningfully distinct creative outcome and selection intent. Otherwise model them as production modifiers/options, not separate styles.
7. **V3:** retain suitable motion-graphics concepts selectively. Do not promise 3D, simulation, complex motion or other advanced production capabilities until verified against actual providers/tools.
8. **V4:** VARIOM's authoritative meaning remains **Story / Testimonial**. Reclassify every MAX V4 record individually; MAX's former Commercial / Advertising Video grouping must not be carried over as a category. A record belongs in VARIOM V4 only when a coherent story is central, or when it contains a genuine, verified and consented testimonial. A commercial objective, cinematic treatment, offer or CTA alone is insufficient.
9. **No automatic production approval.** All 144 source records remain candidates/review items. No import, production exposure or status promotion is authorized by this decision.

## 4. Selection and validation gate

Before any style is approved for VARIOM production:

1. Select only styles that serve a real user need and fit the V2.0 product scope.
2. Review the full record, including prompt instructions, reference provenance, rights, claims, quality checks and production requirements.
3. Test with the intended provider/model and representative Arabic/English brand inputs.
4. Record actual output quality, failure/repair rate, time, human effort, provider cost and product-fidelity issues.
5. Verify all factual claims, product details, identities, testimonials, offers and permissions.
6. Approve only the styles that pass; leave the rest in review/hold.

The initial selection should be intentionally small. The target is a reliable and understandable experience, not maximum library size. No fixed count is imposed before the candidate review.

## 5. Scope and implementation boundary

This approval is a **taxonomy and migration-policy decision only**. It does not authorize:
- importing all or any specific MAX JSON records into application data;
- changing database schemas, APIs, UI, generation workflows or provider integrations;
- exposing all 144 styles to users;
- claiming provider capability, quality, cost or commercial effectiveness without evidence;
- copying third-party reference imagery or treating a reference link as a license;
- changing the authoritative P1–P4 / V1–V4 meanings in the VARIOM Product Vision.
