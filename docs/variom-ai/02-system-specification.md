# VARIOM — Product & System Specification

**Status:** Working specification aligned with VARIOM V2.0.

## 1. Outcome
A brand-aware platform that turns limited user input into marketing ideas, copy and creative assets through a simple bilingual workflow.

## 2. Brand context
Persist brand profile, audience, voice, visual identity and Brand Assets. Reuse known details. No Product Catalog. Product reference images are uploaded manually for each relevant generation task.

## 3. Main workflows
Brand setup/selection; Brand DNA; Monthly Content; Image Studio; Video Studio; Smart Video Editing; Virtual Character; Content Library.

## 4. Functional requirements
- Monthly: up to 3 goals (1 primary + 2 supporting); 8/12/16 posts; images/videos only; no carousel; up to 10 product uploads; optional prices/character; optional template review; no platform choice; image portrait/landscape; video Reels portrait/landscape and <=10 seconds; one progress indicator; results view/open/download; automatic library save.
- Image Studio: P1–P4; one idea or five suggestions; manual product upload; optional price/character; Instagram Portrait/Landscape; internal style choice; actual cost before execution; no initial paid edit loop.
- Video Studio: V1–V4; one idea or five suggestions; manual product upload; optional character; 10/20/30 seconds; Reels Portrait/Landscape; optional scene review; no separate audio controls; internal Master Storyboard mandatory.
- Smart Editing: only repository-approved Simple Smart Editing tasks. Inspect current source before exposing controls.
- Library: images/videos/monthly content; type/date filters; grid/open/download; automatic save. No projects, approvals, ZIP or collections absent separate approval.
- Virtual Character: approved questionnaire and Character Sheet only; save/edit/reuse when implemented.

## 5. Non-functional requirements
Arabic/English and correct RTL/LTR; desktop/mobile; account/brand isolation; secure private assets; idempotent jobs and credit operations; bounded retries/timeouts; partial recovery; accurate media type/MIME; clear states; no false claims about mocks/local renders.

## 6. Credits
Actual quote → balance check → reserve → execute → settle actual → return unused reservation. Preview must not mutate the real ledger.

## 7. Capability truth
A screen is not proof of a working workflow. Report UI, API, persistence, worker, provider, output quality, credits, security and end-to-end evidence separately.

## 8. Exclusions
Product Catalog; monthly publishing calendar; scheduling/publishing; social integration; analytics; approvals; teams/agency workflows; ZIP; professional timeline editor; separate advanced audio controls; 4K; unapproved formats/categories/durations; unapproved paid edit loops.
