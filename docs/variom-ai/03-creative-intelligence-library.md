# VARIOM — Creative Content Intelligence Library

**Status:** Reconciled design baseline. The full detailed MAX library source from the 2026-10-28 conversation was not recovered verbatim; this document does not claim to reproduce it.

## 1. Purpose
An internal decision resource for selecting actionable creative execution styles. It is not a mood-board dump or a guarantee of advertising performance.

## 2. VARIOM taxonomy
Images: P1 Product Showcase; P2 Static Ad; P3 Carousel; P4 Lifestyle.
Videos: V1 UGC; V2 Product Demo; V3 Motion Graphics; V4 Story / Testimonial.
Old MAX definitions must not override these definitions. Detailed styles remain internal.

## 3. Separate dimensions
Content type; primary category; detailed style; marketing objective; subject/message; publishing format; production method; copywriting approach. Do not create a new category from a format, topic, objective or production method.

## 4. Style record fields
Stable ID/version; bilingual name; category; concise/full definitions; actionable execution; composition; camera; lighting; color; movement/pacing; product/brand visibility; text-safe areas; fit/poor-fit; required assets; feasibility; AI suitability; human-review needs; selection signals; alternatives/combination rules; references; provenance; rights; evidence; copy guidance; prompt instructions; quality checks. Unknown facts remain unknown/null.

## 5. Selection rules
Reuse Brand DNA and supplied assets. Respect the selected category and search within it first. Select detailed styles internally. Prefer one primary style and add a secondary only when it has a clear purpose. Prefer simpler feasible execution when quality is comparable. Keep style-match confidence, evidence strength and product-fact confidence separate. Provisional ranking weights are not validated performance probabilities.

## 6. Evidence, rights and truth
Distinguish campaign evidence, research, established practice and creative hypotheses. Record source, date, context, limitations and rights status. Public access does not grant reuse rights. Extract general principles rather than copying protected campaigns. Never invent product claims, results, certifications, testimonials or guarantees.

## 7. Prompt assembly
Combine confirmed facts, objective, category, selected style, brand rules, asset roles, format, approved copy, constraints and success criteria. Separate image text, on-screen text, dialogue, voice-over, captions and CTA. Where Arabic text rendering is unreliable, reserve a text area and compose approved text separately.

## 8. Migration of MAX library assets
Existing taxonomy/style JSON, P1 records, visual references, shot analyses, schemas and manual test cases are candidate assets only. Map semantics to VARIOM before use; identify changed/duplicate/unmapped/deprecated records; preserve provenance and rights; validate schemas; keep seeds separate from production-approved records. Do not bulk-import old P1 records because the label may have changed meaning.


## 9. Current VARIOM registry authority
Document 33 is the normative governance contract for creative taxonomies and style records. Documents 11–14 remain MAX-derived candidate/review material only; none of the 144 candidates, IDs or mappings is approved for production selection or import. The original Creative Content Intelligence Library source remains unrecovered. Until a VARIOM-owned style set is separately approved and supported by provider evidence, production must use only an explicitly approved neutral fallback or keep the affected style-dependent capability unavailable; never silently promote a candidate.
